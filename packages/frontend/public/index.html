Twitch Golf — local dev

  1. Run the EBS: npm run start -w @twitch-golf/ebs
  2. Start a game: curl POST /control with a broadcaster dev token, or open a dashboard link below and use the ingest REPL.
  3. Feed chat: npm run start -w @twitch-golf/ingest then type alice: !70, 50
